# Existence evidence hunt — 2026-10-22

Scope: every catalogued contest (not `upcoming`) for which the archive holds **nothing** — no archived result of any tier and no non-empty website crawl: **177 contests**. The question asked of the open internet, competitive-programming forums and social media was not "where are the results" but "did this contest exist and actually run" — with results/scoreboard URLs collected as a by-product.

Verdicts: **103** confirmed-ran · **17** likely-ran · **13** unclear · **3** likely-not-run · **2** not-yet-held · **39** evidenced-r9-capture-pending

*evidenced-r9-capture-pending* = the 2026-09-06 dark-contest round already found a results/report URL for it (existence not in doubt); it is listed here only because nothing has been captured yet.

Research groups: Z-coordinator-usenet-browser (0 searches, 21 contests); A-brazil (29 searches, 21 contests); B-vietnam (34 searches, 14 contests); C-seasia-taiwan (44 searches, 19 contests); D-preweb-ecna-erc (38 searches, 19 contests); E-socal (30 searches, 14 contests); F-early-na-misc (39 searches, 23 contests); G-europe (45 searches, 16 contests); H-canada-nz-carib (37 searches, 12 contests)

Columns: *tier held* = best result tier the catalogue links to (none of them archived); *verdict* = this pass; *facts* = date/host/winner/teams as found; *evidence* = the sources (F=fetched and read, S=search snippet only). Full detail incl. every evidence item and proposed `sources:` lines: `data/existence-evidence-2026-10-22.json`; capture candidates: `data/url-candidates-existence-2026-10-22.json`.

## Headline findings

- **Existence is settled for almost everything modern.** Every Vietnam National (2012–2025), Brazil Primeira Fase (2008–2026), SEERC (1995–2013 gaps), Malaysia (2014/16/18/19), Caribbean qualifier (2020/21), Atlantic/BOSPRE preliminary and NZPC 2000/2003 edition was found, mostly with a results page that can be captured. The **capture queue** this produces (`data/url-candidates-existence-2026-10-22.json`) is the main deliverable after the report itself.
- **Three catalogue rows probably never happened as catalogued:** `brazil-first-phase-1996` and `-1997` (the Maratona was a single-site event in 1996–97 = the South America regional; the two-phase format only began in 2004) and `algeria-2024` (ACPC's own 2024 calendar has no Algerian contest; the last documented ALCPC is El Oued, Oct 2022; the finder entry is empty). `turkey-2010` (CMS 703) looks like an administrative record: SEERC's 2010 report shows ten Turkish teams competing in Bucharest and says Turkish subregionals would start "next year".
- **Pre-web holes narrowed but not closed.** Usenet (comp.org.acm via Google Groups) and Gordon Cormack's live WF-1994 standings page pin the fall-1993 and fall-1994 regionals of every NA region (GNY, Mid-Central, Mountain, SoCal, ECNA, Far East); CHipCie + the TU/e weekly *Cursor* settle ERC 1988, 1989, 1991 and WERC 1993 (and give a full ERC **1990** scoreboard scan, a bonus). Still unevidenced: ECNA 1984–1988, ERC 1983–1987, RMC 1989, GNY 1996 (certainly ran, no artefact), nena-north-2016, philippines-national-2019.
- **Sources worth adding to the standing toolkit:** Google Groups within-group search (`groups.google.com/g/comp.org.acm/search?q=…`, browser-only); `seerc.icpc.global/<year>/` is live and fetchable (the pipeline's 403 is client-specific — fetch slowly); `hc3.seas.harvard.edu/hc3/bospre/<year>/scoreboard.web.pdf` is live with no Wayback copy (capture now); `maratona.sbc.org.br/hist/<year>/` static tree; `icpcvn.github.io/<year>/national/scoreboard.html`; `matcomgrader.com/contest/standing/<id>`; `scienceatlantic.ca/committees/compsci/icpc/`; `nzprogcontest.org.nz` (2015+) and the Otago `cs.otago.ac.nz/PC/nzcontest/history.html` (pre-2015, robots-blocked → Wayback); `icpccaribe.org` podium pages; `plg.uwaterloo.ca/~gvcormac/acmresults/1994.html`; `chipcie.wisv.ch/archive/<year>/nwercpc/`; `cursor.tue.nl` OCR'd PDF archive.

## How to use the outputs

```
cd ~/Claude/icpc-contests/contests
python3 tools/apply_existence_evidence.py --dry-run          # appends sources: lines (no dates/hosts) — review, then drop --dry-run
env no_proxy='*' NO_PROXY='*' python3 verify_url_candidates.py --candidates contests/data/url-candidates-existence-2026-10-22.json
python3 tools/apply_url_candidates.py --candidates data/url-candidates-existence-2026-10-22.json --statuses verified,dead
python3 tools/validate.py
```
Google Groups thread URLs (`groups.google.com/g/...`) are a JS app: plain-HTTP capture gets an empty shell. Capture them from a browser (the built-in browser's page text, or Save-as from Safari) and file them as `report`/`scoreboard` captures by hand; the other candidates go through the normal pipeline. `seerc.icpc.global` rate-limits parallel fetches — one page at a time.

## Series-level findings

**Z-coordinator-usenet-browser** — Google Groups' comp.org.acm archive (1991-1998) is readable unauthenticated through within-group search URLs (https://groups.google.com/g/comp.org.acm/search?q=...) in a real browser; global Google Groups search needs sign-in. Pages are a JS app, so the capture pipeline cannot fetch them with plain HTTP — a browser-rendered save (built-in browser get_page_text, or 'Save as' on the Mac) is needed. The same posts sit behind the usenetarchives.com locators already on file for ecna-1989/1992/1994, scusa-1991, seusa-1993, socal-1994, taiwan-1993 — usenetarchives.com now serves a Cloudflare human-verification challenge (not bypassed). The 1992-93 RCD list names every region's director (host institution proxy).
