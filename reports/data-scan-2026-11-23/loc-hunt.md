# loc-hunt: contests with neither `location` nor `sites`

## What was checked (rerunnable: work/gen.py, gen2.py, q.py/fx.py/ex.py)
- Blank = no `location` and no `sites` in the worktree: 196 contests at the start (wave 1 had already filled others), 110 left after these ops.
- NEERC subregionals: the catalogue's own `web` source (neerc.ifmo.ru/subregions/<name>.html) was read in Wayback (q.py lists snapshots, fx.py fetches them, ex.py extracts "Host city / Host university / ... subregional contest took place in X on <date>"). One snapshot per contest season was used, the sentence about THAT edition (never the series' usual host). Older editions: the Archive/<year>/<subregion>.html result pages and Archive/98/results.htm ("Central Subregional Quarter Final Rybinsk, October, 7, 1998" etc.), which carry the host.
- Others: held scoreboard pages (sweden-1999..2001 "parallellt i ..."), the CHipCie (Delft) NWERC archive listing of every ERC/WERC/NWERC edition with city and date, the held 1996 Maratona page (UFMG, Belo Horizonte).
- Not inferred from series or other editions anywhere. `location` is "City, University" as the page prints it; `sites` uses the institution node where one matches (RSATU, BSU, SSU, FEFU, MSU, UrFU alias), else the city node.

## Items for discussion with Fredrik
1. **NZPC and South Pacific site-code lists (not applied, per instruction).** Held results show only codes: nzpc-2000 "AK, DD, HA"; nzpc-2002 "AKL, DUD, HLZ, WAN, WGN"; nzpc-2004 "AKL, DUD, HML, WEL (and school codes)"; nzpc-2005 "HML, DUD, AKL, WEL, CCH"; nzpc-2006 "AKL, HML, DUD, CHC, WLG"; nzpc-2007 "AKL, HML, WEL, CCH". From 2008 results list universities, from 2015 only winners (nzprogcontest.org.nz). Question: are codes a primary statement of location (sites Auckland, Dunedin, Hamilton, Wellington, Christchurch)? For: the codes are the organisers' own, and sites exist as nodes (nz-auckland, nz-dunedin, nz-hamilton ...). Against: a code is not a place name (HA=Hamilton is my reading; AK/DD/HA 2000 page text says "Hamilton site", "Auckland"). Recommend yes for 2000-2007 with `name` = the code; nothing for 2008+ (team universities are not sites). South Pacific 1991-97 results hold only champions; no venue: leave.
2. **Contests that stay blank (110, list in data.json)** because no held or live page names the place: alberta-2003..2010/2025 (online/distributed to home universities: 2007 page says teams from Lethbridge, Calgary, Alberta; alberta-2006 has such a multi-university string; same string for 2007 would be a reading, not a quote), ecna/scusa/seusa/mausa/gny/pacnw/cerc/swerc-1990s (scoreboards and Usenet lists without venue; scusa-1991 only says results were on tamu's FTP server), erc-1983..86 (Felix 692/720 are scanned images, erc-1985 Felix 728 says only that a team from Imperial College won a place in the finals), hungary-2024/25, nordic-2004, caribbean-2009, dhaka-1997, neerc-1996/97, rmc-1995, shanghai-2022, upcoming hefei/jinan/kunming-2026. A describe-style OCR round over the Felix PDFs and Usenet posts is the way; I did not guess.
3. **Real conflicts found** (not applied):
   - central-russia-2001: Archive/2001/central.html says "Host: Rybinsk Host university: Rybinsk SAAT City: Moscow". Which is it? Recommend Rybinsk after a second page.
   - urals-2000: neerc says Perm State University hosted; sp.urfu.ru/chu/2000 is the Ural championship in Yekaterinburg and is also a source. Applied Perm (applies to the NEERC subregion). Needs a node ru-perm and ru-perm-psu (not in locations.yaml; I did not edit it).
   - urals-2004/2005: neerc page says "took place in Yekaterinburg on April 10-14, 2004 / April 19-24, 2005" (spring Ural championship dates) while the contest ids are the autumn seasons; not applied. urals-1999 (sp.urfu.ru, Ural State University, 19-20 Mar 1999) likewise.
   - georgia-2004: page says "Azerbaijan and Georgia subregional contest took place in Tbilisi"; applied Tbilisi.
4. **locations.yaml duplicates**: br-belo-horizonte-ufmg and br-belo-horizonte-universidade-federal-de-minas-gerais are both UFMG (3 and 2 uses); merge. Also no nodes for Perm and its university; Krasnoyarsk State Technical University, Tashkent University of Information Technologies, Kyrgyz-Russian Slavic University, Yerevan State University, Baku State University, Tbilisi State University, Novosibirsk State Technical University, Kazakh National University: I used city nodes; recommend adding institution nodes (data.json would be the list) so `sites` can be institution-level.
5. Several NEERC subregion contests carry a CMS-less `date` of null (about 100 contests have no `date`; the ex.txt page sentences give them, e.g. central-russia-2004 20-21 Oct 2004). Worth a date round using the same pages; I did not set dates (outside the location task).
