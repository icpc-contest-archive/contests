## Rules applied

- Per (contest, judge, url) the newest live capture is used, else the newest Wayback one; a capture that lists no problems falls back to the next older one (section *newer capture unusable*).
- Titles match by normalised name; a page whose letters agree with the contest's letter map also matches an unmatched title through its letter (*matched by letter only*: Korean translations on Baekjoon, Portuguese/English pairs for Latin America); a page whose letters contradict the map gets links on name matches only (*letter check*). The last unmatched title of a complete set takes the last unlinked row (*matched by elimination*).
- Rows are created from a page only for a set with no rows or `complete: false`, never past the set's `count` (*held back*), and never with a Korean/CJK title (*translated title, no row to match*; `--allow-translated-names` would create them). Created ids are p- + sha1(set|letter|name)[:8].
- Page letters fill a contest's letter map where both the letter and the row were unmapped; `letters: unknown` is dropped once a member contest has a map (DEFINITIONS.md: it says no map is known for any contest).
- Baekjoon links carry `as_of` = the Wayback snapshot mined (the judge closed 2026-04-28); Baekjoon practice problems (letters PA, PB, …) and Practice Session sections are skipped.
- Kattis contest pages give the contest-page URL as the link; open.kattis.com is added only when the same short name is on a problem-sources page of the set.
- Pages are applied in two passes per set so a page processed before another page created the rows still gets its links; a rerun changes nothing.
